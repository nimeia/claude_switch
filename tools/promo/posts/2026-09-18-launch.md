## reddit

title: I built a free Windows tray app that switches Claude Code accounts when you hit the 5-hour limit

I use Claude Code most of the day, and the 5-hour limit kept landing in the middle of a task. The fix was always the same: log out, log in with my other account, restart, re-explain where I was. So I built a small tray app to do that part for me.

What it does:

- Shows the 5-hour and 7-day usage left on every account you've added, side by side
- When the account you're on crosses a threshold (90% by default), it switches to the one with the most left. It also moves on when an account is broken (expired login, no subscription) instead of waiting for a number
- The switch lands in the session you're already in: on Windows the credentials are just files, and Claude Code picks up the new ones on your next message. No restart, no reopening VS Code
- You can open a terminal as a specific account next to your normal login, and turn on a status line that shows which account each terminal is on and how much it has left

Worth knowing before you try it:

- Windows only for now; a single portable .exe, no installer
- It isn't code-signed, so SmartScreen warns on first run. The source is on GitHub and each release ships SHA256 checksums if you'd rather verify it or build it yourself
- It works with logins you already have: sign in with claude as usual, then click Add account. Apart from the usage checks it sends to Anthropic, nothing leaves your machine
- Not affiliated with Anthropic
